# What MCP means for your company

## Who it helps

| Role | What changes |
|---|---|
| **Sales and revenue operations** | Ask the CRM questions in plain language, prepare updates for review |
| **Finance and operations** | Look up ERP records, find exceptions, draft reconciliations |
| **Data and engineering** | Build and fix integrations from a conversation instead of a ticket |
| **IT and security** | One controlled door per system instead of ad hoc exports, with a log |
| **Leadership** | Faster answers from live data, with a clear approval trail |

## Common first uses

1. **Read-only questions** on one system.
2. **Investigations**: why did this sync or workflow fail, which records are affected.
3. **Drafts for review**: emails, field updates, reconciliations.
4. **Building**: a sync, a workflow or an agent described in plain language and saved after you review it.

## Readiness checklist

- [ ] One system and five questions you can check by hand.
- [ ] A named owner for the connection.
- [ ] A **narrow** account for the assistant, not an admin login.
- [ ] Read-only first. Write tools off until you trust the reads.
- [ ] A rule for what needs approval.
- [ ] A way to see what happened afterwards (a log).
- [ ] A decision on what data must never reach an assistant (for example regulated personal or health data).
- [ ] Agreement from IT or security on which assistants and plans are allowed.

## When MCP is not the answer

- You need two systems to stay identical: use a [two-way sync](https://www.stacksync.com/two-way-sync).
- You need the same step every time on a trigger: use a [workflow](https://www.stacksync.com/workflow-automation).
- You need an internal tool your whole team opens from a link: build it on a platform such as [Enterprise OS](https://www.stacksync.com/enterprise-os), which hosts the app, a database and workspace access.

## What to measure

Measure the questions answered correctly against a hand check, and the changes that needed correcting after approval. This repo makes no claim about savings or speed, and you should not either until you have your own numbers.
