# Contributing

- **MCP or an assistant's menus changed:** update the doc and name the official page and the date you checked.
- **A new term:** add one line to `docs/glossary.md`.
- **A new example:** add it to `docs/crm-examples.md` or `docs/erp-examples.md` with the limit that applies.
- **A new rule for the job helper:** add it to `code/should_i_use_mcp.py` with a test in `code/tests/test_code.py`.
- Describe behavior, not outcomes. No performance, savings or compliance claims.
- Do not call two-way sync "one-way". For restrictions say read-only.
- Use synthetic data only. Never include real tokens, record ids or customer data.
